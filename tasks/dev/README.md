# Public development tasks

Ten small synthetic bugs with a shared solve(array) interface. These are development fixtures, not upstream issues or held-out benchmarks. Reference solutions live outside task prompts in tests/fixtures/dev. Each task pins its source, spec, acceptance and evaluation bytes. Evaluation is scored only after generation stops.

- binary-search
- chunk-list
- flatten-once
- run-length
- moving-average
- stable-difference
- rotate-list
- balanced-brackets
- dependency-order
- group-totals
